Deploy GriffinModule

The GRIFFIN module for Safe on Robinhood Chain. Each Safe that enables it writes its own charter; an AI agent then spends from that Safe only inside the charter, with Griffin's signature on every move. The module has no owner and no admin: once deployed nobody can change it, and it can move nothing a Safe did not allow.
