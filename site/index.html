Your agent holds one key.
Griffin holds the other.

An AI agent with a hot wallet is one bad prompt away from empty. Put its funds in a Squads wallet that needs two votes. The agent casts one. Griffin casts the second only when the move fits the charter you signed.

Three keys, two votes

The agent can ask. It can't take.

Every Griffin wallet is a plain Squads v4 multisig on Solana. Nothing custom holds your funds, and you can read every member and rule on chain.

Key 1 · you

Owner

  • Signs the charter
  • Swaps the agent key in one transaction
  • Can dismiss Griffin alone, any time
  • Your own moves always pass
Key 2 · your bot

Agent

  • Lives on the agent's machine
  • Proposes moves and votes for them
  • One vote is never enough
  • A leaked agent key can't drain the wallet
Key 3 · the guard

Griffin

  • Can only vote, can't propose
  • Simulates each move first
  • Votes yes inside the charter
  • Says no, with reasons, outside it
