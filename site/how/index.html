How it works

One move, from the agent asking to the money landing, and who can do what along the way.

The keys

Three keys, two votes

The wallet is a Squads v4 multisig: threshold 2, no time lock. You are the config authority, so the membership is yours to change without asking anyone.

Key 1 · you

Owner

  • Signs the charter
  • Swaps the agent key in one transaction
  • Can dismiss Griffin alone, any time
  • Your own moves always pass
Key 2 · your bot

Agent

  • Lives on the agent's machine
  • Proposes moves and votes for them
  • One vote is never enough
  • A leaked agent key can't drain the wallet
Key 3 · the guard

Griffin

  • Can only vote, can't propose
  • Simulates each move first
  • Votes yes inside the charter
  • Says no, with reasons, outside it
One move

From proposal to release

  1. The agent proposes.It creates a vault transaction and a proposal, and votes for it. That is 1 of 2. Nothing can move yet.
  2. It asks Griffin.One call: POST /v1/guard with the wallet and the move's number, or the griffin_send_sol / griffin_swap tools that do all of it.
  3. Griffin reads it from chain and runs it.It simulates its own vote plus the execution and reads every account the move writes, before and after. What counts is what the simulation shows leaving the wallet, not what the agent says.
  4. The charter decides.Recipients, programs, SOL and token limits, the 24 hour total, and the moves that are never allowed.
  5. PASSED or TURNED BACK.Passed: Griffin returns a transaction with its vote, the execution and the cleanup, already signed by Griffin. The agent signs as fee payer and sends it. Turned back: the reasons, and the proposal stays at 1 of 2.
Your side

The owner keeps the crown

Your own moves pass without a check. From the app, Griffin adds its vote itself after you sign, because wallets like Phantom add their own instructions to a transaction and that would void a signature made in advance.

If the agent's machine is lost, swap the agent key in one transaction. If Griffin is down or you stop trusting it, dismiss it in one transaction and the wallet becomes yours alone. No vote, no wait.
